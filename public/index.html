Before you order

What do I get?

One HTML file, sent to your email. It needs no installer and no account. NUBO Dashboard already includes the invoice generator, so you do not need to buy both.

Which one should I pick?

Pick NUBO Invoice if you only need to send invoices. Pick NUBO Dashboard if you also want to track clients, finances and tasks.

Is the price a one-time payment?

Yes. The price on the card is the full price. Nothing renews and nothing expires.

Where is my data stored?

In your own browser, on your own device. We do not run a server that holds your clients or invoices. Because of that, keep using the same browser profile you set the tool up in.

Do the AI features cost extra?

They need a free Groq API key, which you add to the tool yourself. When you use the AI Advisor or Content AI, what you type is sent to Groq. The rest of the tool works without a key.

Does it work offline?

NUBO Invoice does. NUBO Dashboard runs from a single file in your browser, but its AI features need an internet connection.

Can you build something for me?

Yes. We take custom AI tools, automations and websites. See Custom work further down.
